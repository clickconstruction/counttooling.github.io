Plumbing track

Fixture counting and pipe measuring, the plumbing way.

New here? Start with The Basics first — this track assumes it.

Build a plumbing palette fast, make the plan read like your trade, handle mixed-scale sheets, and run a full plumbing takeoff.

1 Building your palette in two clicks The Quick Count and Quick Line creators build correctly-named counters and line types from Size, Type, and Material pickers — no typing, consistent names. 2 Custom icons — make the plan read like your trade Pick from the built-in trade icon library or upload your own SVG symbols, manage and reorder them, and carry your icon library between devices. 3 Scale zones and multiply zones Handle multi-scale sheets and repeated areas — give a region its own scale, or multiply everything inside a boundary so typical floors and units count correctly. 4 Doing a plumbing takeoff Count fixtures, measure pipe runs, and price plumbing work straight off the plan PDF — custom counters, scale zones, and exports built for plumbing estimating.
