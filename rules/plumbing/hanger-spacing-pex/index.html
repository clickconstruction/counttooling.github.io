Hanger spacing for PEX

How far apart PEX tubing may be supported — 32 inches horizontal at 1 inch and smaller, 48 inches at 1-1/4 inch and larger, 10 feet vertical.

Amendments

No state or local amendment to this rule is on file. Not on file means the model code as written — check your jurisdiction.

A model code the authority having jurisdiction adopts.

PEX sags between supports, so the code caps the run between hangers tightly for the small sizes. On a takeoff that is one hanger per 32 inches of horizontal 1-inch-and-smaller PEX, rounded up per run — two 13-foot runs are five hangers each, ten in all.

Status

Written down, not yet wired: the app's child counts count in whole feet today, so the plumbing tour's "one hanger per 4 ft" is a placeholder until child counts take an interval in inches and the Child counts editor offers this rule by name. Until then, add the hanger as a child count yourself.

Verify against your edition

The Uniform Plumbing Code reads the same for PEX (UPC Table 313.3). Check the edition your jurisdiction adopts before a bid rides on the number.
